# ZERO ONE V2

A clean rebuild of the ZERO ONE creative studio website.

## Direction

Editorial, dark, premium and minimal — inspired by the supplied reference while preserving ZERO ONE's core DNA:

- From 0 to 1. And beyond.
- Black / off-white / acid green
- Oversized typography
- Premium editorial spacing
- Case-study-first portfolio
- Clear service architecture
- Pricing / plans
- Scroll-driven reveal motion
- Subtle cursor and magnetic interactions
- Responsive and reduced-motion friendly

## Structure

- Hero
- Selected work
- Services
- Process
- Point of view
- Plans
- Contact
- Footer

## Run

Open `index.html` directly, or serve the folder with any static web server.
